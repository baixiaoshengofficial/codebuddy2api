# CodeBuddy2API 控制台设计规范

依据 ui-ux-pro-max 的 Minimalism & Swiss Style、Operations 模式及 Vue composable 指引，按现有管理工具用途取舍。配色按用户最新要求使用 Element UI Theme Chalk 默认体系（主色 #409EFF，成功 #67C23A，警告 #E6A23C，危险 #F56C6C）；暗色参考 Element Plus 官方中性色与混色变量。不采用营销落地页结构或外部字体。

- 页面优先展示状态、数据与操作。凭证路由保持紧凑，规则和历史放在次级区域；不编造指标或计费结果。
- 颜色沿用 `styles/tokens.css` 的语义变量：蓝色表示交互和当前选择，绿色表示可用或成功，橙色提醒，红色异常。当前使用与可用共用标签结构，仅更换底色、文字色。
- 字号：正文 16px，表格及辅助信息 14px / 12px，页面标题 28px，区块标题 16px。中文使用系统字体，代码与数字使用系统等宽字体或表格数字。
- 间距按 4 / 8 / 12 / 16 / 24 / 32px；统一圆角、阴影和控件高度。移动端输入框与主要操作区至少 44px，桌面密集表格操作可用 36px。
- 375px、768px、1024px、1440px 下均应可用。手机端表格转为信息卡片，筛选按网格换行；根容器始终铺满动态视口。
- 导航支持直接链接、浏览器前进后退和当前页面提示。设置未保存时保留离开确认。移动菜单与抽屉共用原生对话框行为，支持 Escape、焦点限制、关闭后焦点返回。
- 输入框有可见标签；错误、空数据和加载反馈统一。自动刷新展示更新时间，不把缓存结果标为实时；金额、凭证状态和额度明细保持不同的视觉语义。
- 正文与辅助文字对比度至少 4.5:1，小字号状态使用同色系深色文字；主按钮按用户要求保留 Element UI 默认蓝底白字，不将其宣称为全面的 WCAG AA 合规；所有操作有键盘焦点与可访问名称。装饰图标从可访问树隐藏。低动态偏好下取消非必要动画。

结构：应用入口负责认证；AppShell 负责页面装配；导航、主题、对话框行为由独立 composable 管理；领域页面继续使用原有 API 服务。样式按基础、共享组件与功能域拆分，不在文件末尾堆叠覆盖规则。
